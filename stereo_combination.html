Combining the stereo events: sst1mpipe-stereo

The SST-1M telescopes have no array trigger: each telescope writes its own events, one raw data (zfits) file per run and per telescope. Each run is processed into a DL1 file by sst1mpipe-process (see Processing the data with the ctapipe tools), the DL1 files of the runs of a night are merged for each telescope (ctapipe-merge, see 3. Merging), and the coincident events of the merged files of the telescopes are combined into stereo events by sst1mpipe-stereo, a ctapipe.core.Tool:

SST1M1_20260120_merged.dl1.h5 ─┐
                               ├──► sst1mpipe-stereo ──► SST1M_20260120_merged.stereo.dl1.h5
SST1M2_20260120_merged.dl1.h5 ─┘

The coincident events are matched and combined by a StereoEventCombiner. The stereo reconstruction (stereo DL2) is a later step.

Usage

sst1mpipe-stereo \
    --input SST1M1_20260120_merged.dl1.h5 \
    --input SST1M2_20260120_merged.dl1.h5 \
    --output SST1M_20260120_merged.stereo.dl1.h5 \
    --config sst1mpipe/resources/config/sst1mpipe_data_config.json

sst1mpipe-stereo --help lists the options (--help-all all the settings). The default settings are in sst1mpipe_data_config.json.

Warning

The combination does not work properly with more than two telescopes, see StereoEventCombiner.

Combiners

The matching method is chosen with --combiner: each combiner implements the matching of the events of two telescopes, and the combination of each part of the event is a method of the base class, which a child combiner can override.

class sst1mpipe.stereo.StereoEventCombiner(*args: t.Any, **kwargs: t.Any)

Base class of the combination of the coincident events of the telescopes into stereo events.

A combiner matches the coincident events of the telescopes (match, from their trigger tables) and combines the matched events into a stereo event (combine). The child classes implement the matching of the events of two telescopes (match_pair), and can override the combination of any part of the event (combine_<part> methods).

The events of each telescope are matched to those of the reference telescope (reference_tel_id): a stereo event is an event of the reference telescope with the coincident events of the other telescopes, and has the obs_id and event_id of the event of the reference telescope. Only the events of type SUBARRAY are matched, and each event is in at most one stereo event. Swapping the reference telescope changes the ids of the stereo events; the stereo events are the same with WhiteRabbitClosestCombiner and SWATEventIdCombiner.

Parameters:
configtraitlets.config.Config, optional

Configuration of the combiner, e.g. Config({"WhiteRabbitClosestCombiner": {"max_time_diff": 5 * u.us}}). The configuration of StereoEventCombiner (e.g. reference_tel_id) applies to all the combiners.

parentctapipe.core.Component or ctapipe.core.Tool, optional

Parent of the combiner, whose configuration is used.

**kwargs

Values of the configuration options, e.g. reference_tel_id=22.

Warning

The combination does not work properly with more than two telescopes: the coincidences of telescopes without an event of the reference telescope are not combined (they are mono events). It is tested with three telescopes on made-up trigger tables only, and not with more than three telescopes. TODO:

  • test the combination of more than three telescopes, and of three telescopes on real data

  • match the coincidences of telescopes without an event of the reference telescope (matching of all the telescopes at once)

  • define the combination of different array pointings (combine_array_pointing)

class sst1mpipe.stereo.WhiteRabbitClosestCombiner(*args: t.Any, **kwargs: t.Any)

Coincident events: closest White Rabbit trigger times.

For data with White Rabbit timestamps (ns precision, data taken after 25 September 2023). Each event of the reference telescope is matched to the event of the other telescope with the closest trigger time, if their trigger times differ by less than max_time_diff, and if it is also the closest event of the reference telescope to that event (mutual closest events): each event is matched at most once.

The trigger times of the coincident events of the SST-1M telescopes differ by a few tens of ns (e.g. 32 and 48 ns in the test data), while the events of a telescope are hundreds of µs apart at the usual trigger rates: the default max_time_diff (10 µs) does not give random coincidences.

class sst1mpipe.stereo.SlidingWindowCombiner(*args: t.Any, **kwargs: t.Any)

Coincident events: trigger times within a window, after the search of the offset between the clocks.

For data without White Rabbit timestamps (taken before 25 September 2023), whose clocks have an offset. An event of the other telescope is coincident with an event of the reference telescope if its trigger time is within window_half_width (strictly) of the trigger time of the event of the reference telescope plus the offset of the clocks (time of the other telescope - time of the reference telescope).

The offset is time_offset if given. Otherwise, it is the offset giving the most coincident events among the offsets from offset_start to offset_stop (excluded) in steps of offset_step (the first one if several give as many), kept in last_time_offset.

An event with several events of the other telescope in its window is ambiguous and not matched, in both directions: an event of the reference telescope is matched only if its window has a single event of the other telescope, whose window (time - offset) has a single event of the reference telescope.

With the default window (1 ms), the method gives random coincidences at the usual trigger rates: it is meant for data without precise timestamps, otherwise use WhiteRabbitClosestCombiner (or a fixed time_offset with a narrow window). With a searched offset, swapping the reference telescope can give other stereo events.

class sst1mpipe.stereo.SWATEventIdCombiner(*args: t.Any, **kwargs: t.Any)

Coincident events: same array event id given by SWAT.

For data taken after 30 January 2024: SWAT gives the coincident events of the telescopes the same array event id (arrayEvtNum of the raw data), which is the event_id of the events in the DL1 files. Only the event ids are used: the events without the same id are not matched, whatever their trigger times, and nothing else is tried if the files have no SWAT event ids. An id found several times in the events of a telescope is not matched.

Examples

Matching of the events of the merged files of a night, without the tool:

from sst1mpipe.scripts.sst1mpipe_stereo_tool import read_telescope_triggers
from sst1mpipe.stereo import StereoEventCombiner

triggers = {
    21: read_telescope_triggers(["SST1M1_20260120_merged.dl1.h5"]),
    22: read_telescope_triggers(["SST1M2_20260120_merged.dl1.h5"]),
}
combiner = StereoEventCombiner.from_name("SWATEventIdCombiner")
groups = combiner.match(triggers)
print(triggers[22][groups[22]][["obs_id", "event_id"]])

A child combiner overriding a part of the combination (it must be imported before the tool is configured, to be found by --combiner):

from sst1mpipe.stereo import WhiteRabbitClosestCombiner


class LowestTelescopeIds(WhiteRabbitClosestCombiner):
    """stereo events with the ids of the event of the lowest telescope id"""

    def combine_index(self, stereo, events):
        stereo.index = events[min(events)].index

class sst1mpipe.scripts.sst1mpipe_stereo_tool.StereoTool(*args: t.Any, **kwargs: t.Any)

Combination of the coincident events of the SST-1M telescopes into stereo events (sst1mpipe-stereo).

The input files are DL1 files of a single telescope each (sst1mpipe-process), e.g. the DL1 file of a night of each telescope (runs merged with ctapipe-merge), any number of files per telescope, of at least two telescopes including the reference telescope of the combiner. Simulated files are refused.

The output file has the stereo events, and with keep_mono the events which are not combined (mono events, unchanged), in time order; the data levels written are the settings of the DataWriter. It also has the subarray of all the telescopes, the observation and scheduling blocks of the runs and, with copy_monitoring, the monitoring data of the input files. It has no stereo DL2 and no /dl1/info.

  1. setup: the input files are grouped by telescope and sorted by time, the trigger tables of the telescopes are read (read_telescope_triggers) and the output file is opened with the ctapipe DataWriter.

  2. start: the coincident events are matched by the combiner (combiner_type, match), then the events are read from the files (TelescopeEventReader), combined (combine) and written in time order, with the mono events if keep_mono.

  3. finish: the output file is closed, the monitoring tables of the input files which have events in the output are appended (copy_monitoring, append_monitoring_tables) and the numbers of stereo and mono events are logged.

The pointing of the telescopes interpolated at the time of each event by the HDF5EventSource (monitoring data of the files) is not written in the output file: an event out of the time range of its pointing table gets a NaN pointing instead of stopping the tool (PointingInterpolator.bounds_error is False unless configured).

sst1mpipe.stereo.nearest_index(sorted_values, values)

Index of the nearest element of a sorted array to each of the given values.

Used by WhiteRabbitClosestCombiner to find, for each trigger time of a telescope, the closest trigger time of another telescope, for all the events at once (no loop over the events).

For each value, numpy.searchsorted gives the position where it would be inserted in sorted_values: the elements just before (left neighbour) and at (right neighbour) this position are the two candidates, the smaller and the larger elements closest to the value. The nearest of the two is kept, the left one if both are as near. A value below the first element or above the last one has a single candidate, the first or the last element. The cost is O(n log m) for n values and m sorted values.

Parameters:
sorted_valuesarray-like

Values sorted in increasing order, not empty.

valuesarray-like

Values whose nearest element is searched.

Returns:
numpy.ndarray

For each of values, the index of the nearest element of sorted_values: the first one if two elements are as near.

Examples

>>> nearest_index([0, 10, 20], [4, 5, 6, 100])
array([0, 0, 1, 2])
